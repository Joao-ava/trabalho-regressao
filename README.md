# Trabalho Regressão

Trabalho para matéria de inteligência artificial computacional

## Estrutura

```sh
. # raiz do projeto
├───requirements.txt # dependências
├───app # código do projeto
└───data # dados para o projeto
```

## Instalação

Ao baixar o projeto crie um ambiente virtual python e instale as dependências como segue as instruções a seguir para cada sistema operacional:

### Linux

```sh
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Windows

```sh
python -m venv venv
venv/Scripts/Activate.ps1
pip install -r requirements.txt
```
